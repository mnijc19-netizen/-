# 极智全域个人资产与财务管理系统 (SmartWealth Pro)

> **全域资产穿透 • 智能短信/通知识别 • 懒人余额快照 • 零摩擦防放弃 • 100% 本地隐私安全**

---

## 🌟 核心设计理念：解决“记账繁琐容易放弃”痛点

针对**“每天记账太累、容易忘记、资产分散在微信/支付宝/多家银行/股票/房产/负债而无法全局掌控”**的问题，本系统提供五重**零摩擦与自动化减负方案**：

1. **📱 手机短信与通知智能识别（复制即记账）**
   - 复制手机收到的银行扣款短信、微信支付凭证、支付宝消费通知或自然语言一句话（如“昨晚海底捞吃了320”）。
   - 打开系统后点击「读取剪贴板」或粘贴，系统秒级自动提取**金额、商户、卡号、时间、分类与变动后余额**，一键确认即可完成记账。
2. **📥 微信 / 支付宝官方账单 CSV 10秒全量同步**
   - 支持月底/周度直接将微信或支付宝导出的账单明细 CSV 文件拖拽上传，系统自动去重、自动分类，实现**“平时不用管，月底拖一次”**。
3. **📸 懒人余额快照模式（大数法则对账）**
   - 不想记录每一笔碎银几两的用户，只需每周/每月填写一次各大账户当前余额，系统自动反推净资产增减与真实财富增长曲线。
4. **🔄 周期性固定收支自动生成（Auto-Ledger）**
   - 一次性配置每月工资发放、房贷月供、宽带物业费、影视音乐会员订阅（iCloud/网易云等），系统在指定日期自动记账。
5. **🛡️ 100% 本地存储与私有化保障**
   - 基于 SQLite 本地数据库与 FastAPI，财务数据完全留存在您本地电脑中，绝不上传任何第三方云端。

## 🚀 快速启动指南

### 方式一：双击一键启动 (推荐)
直接双击根目录下的 **`start.bat`**，系统将自动初始化数据库、启动服务并打开浏览器访问 `http://127.0.0.1:8000`。

### 方式二：Python 命令启动
```bash
python start.py
```

### 方式三：前后端分离开发模式
- **后端**：
  ```bash
  python -m uvicorn backend.main:app --reload --port 8000
  ```
- **前端**：
  ```bash
  cd frontend
  npm run dev
  ```
  访问 `http://localhost:3000`

## 📊 系统核心功能模块

| 功能模块 | 核心特性 |
| :--- | :--- |
| **📊 财务总览 (Dashboard)** | 全局净资产大盘、本月收支结余、储蓄率、近6个月趋势对比、资产配置环形图、智能财务体检评分与诊断建议 |
| **💳 资产矩阵 (Accounts)** | 穿透现金、银行卡、微信/支付宝钱包、A股/港美股、加密货币、自住房产、对外借款、信用卡及房贷等多资产多币种统一核算 |
| **🧾 账单流水 (Transactions)** | 多维度检索（分类、账户、时间、类型、关键字）、多标签支持（如 `#旅游`、`#聚餐`）、流水删除余额自动回滚、CSV 报表导出 |
| **🤖 智能识别中心 (Smart Parser)** | 20+ 主流银行短信模板、微信支付凭证识别、支付宝交易通知提取、NLP自然语言记账、官方 CSV 账单批量导入与去重 |
| **🎯 预算与风控 (Budgets)** | 月度总预算与各分类预算设定、动态彩色进度环（正常绿/预警黄/超支红）、剩余额度测算 |
| **📈 投资理财 (Investments)** | 股票、公募基金、ETF、加密货币持仓成本、最新市值、浮动盈亏与收益率追踪 |
| **💳 负债与信用 (Debts)** | 信用卡账单日/还款日提醒、免息期日历、房贷月供进度、雪球还债法与雪崩还债法模拟器 |
| **📊 深度分析 (Analytics)** | 资金流向**桑基拓扑图 (Sankey Flow)**「收入源 → 账户 → 支出归宿」、消费品类雷达画像 |
| **🌟 心愿目标 (Goals)** | 愿望资金存入（达成时触发彩带庆贺效果）、倒计时月均储蓄规划建议 |
| **⚙️ 系统设置 (Settings)** | 一键载入全场景逼真演示数据、全量 JSON 备份与还原、周期自动记账规则管理 |

## 🛠️ 技术架构

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS v4 + Lucide Icons + ECharts + Canvas Confetti
- **后端**：Python 3.10+ + FastAPI + SQLite + Pydantic + Uvicorn
