# 💎 SmartWealth Pro (斌斌钱包)

> **极智全域个人与家庭资产智能财务管理系统**  
> 专为 iPhone 与现代移动端设计的零摩擦记账、AI 视觉驱动与全资产管理系统。

---

## 🌟 核心特性

- 📱 **Mobile-First Apple HIG 液态毛玻璃美学**：沉浸式视觉体验，支持全息暗黑模式与灵动粒子动效。
- ⚡ **iPhone 硬件级秒存**：绑定 Action Button / 轻点背面，付款后长按 1 秒自动识图入账。
- 🤖 **AI 视觉多模态大脑**：深度融合智谱 GLM-4.6V，支持消费小票、多卡聚合开账、证券持仓与分期还款自动识别。
- 🛡️ **宪法级数据安全与复式记账**：`净资产 = 总资产 - 总负债`，敏感资产默认隐私掩码，双层哈希防重复记账。
- 📊 **多维深度财务分析**：自由现金流预测、分类支出占比（自动剥离余额校准流水）、预算智能预警。
