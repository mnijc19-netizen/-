# 🚀 SmartWealth Pro · 项目全景白皮书与极速上手指南

> **系统名称**：SmartWealth Pro (极智全域个人资产与财务管理系统 · 斌斌钱包)  
> **核心定位**：专为移动端打造的极致零摩擦、全资产聚合、AI 视觉驱动、复式记账与资金规划系统。

---

## 🛠️ 技术栈全景

- **前端架构**：React 19 + TypeScript + Vite 8 + Tailwind CSS 4
- **UI 风格**：Apple HIG 设计语言 + iOS 液态毛玻璃 (Liquid Glass Material) + 高清暗黑模式
- **可视化引擎**：ECharts + Lucide React + Canvas Confetti
- **智能大脑**：智谱 GLM-4.6V (多模态视觉) / GLM-4.5-Air / DeepSeek / OpenAI 通用兼容
- **自动化集成**：iOS 快捷指令 (Action Button / Back Tap) + GitHub Gist 私有云信箱
- **部署模式**：GitHub Pages 纯静态离线模式 (`https://mnijc19-netizen.github.io/-/`) + 本地 FastAPI 双模自适应

---

## 📱 核心功能矩阵

1. **全域资产聚合大厅**：
   - 覆盖现金、微信、支付宝、储蓄卡、证券A股/美股/ETF、基金、加密货币、房产车辆固定资产；
   - 负债信贷专区：信用卡、蚂蚁花呗、京东白条、美团月付、抖音月付、房贷车贷。
2. **零摩擦极速记账体系**：
   - iPhone 侧边按键 / 双击背面 1 秒静默截屏记账；
   - Universal 5-in-1 底部快捷记账面板（手动、拍照、智能文本、批量开账、剪贴板）；
   - 微信/支付宝官方 CSV 账单月度 10 秒批量导入去重。
3. **AI 财务智能大脑**：
   - 智能看图识小票、账单截图、多银行卡卡面开账、券商持仓一键录入；
   - 自然语言多轮对话记账与流水修改（`update_transaction`）；
   - 月度资金规划方案生成器（`planner`）。
4. **资金规划与分期大厅**：
   - 自动推算未来各月待还分期（花呗/白条/美团/车房贷）；
   - 动态计算当月自由支配现金流与安全消费余量。
